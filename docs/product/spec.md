# 仕様

1 人で使う家計簿。収入と支出を記録し、月ごとに集計して見る。
データはブラウザの localStorage にだけ置き、ログイン・同期・複数通貨は扱わない。

この文書が機能の SSoT である。Issue は節を指し、仕様を Issue に書き写さない。
仕様に無い機能を作るときは、先にこの文書に節を足す。

## データ

```ts
type Transaction = {
  id: string; // crypto.randomUUID()
  date: string; // "YYYY-MM-DD"（利用者の端末の日付）
  type: "income" | "expense";
  amount: number; // 円。1 以上の整数
  categoryId: string; // 「カテゴリ」の id。type が同じカテゴリだけ
  memo: string; // 空でもよい。100 文字まで
};
```

- 金額は円の整数だけを扱い、浮動小数で計算しない。入力の読み取りは共通の `parseAmount` を使う。
- 月は `"YYYY-MM"` の文字列で表し、`date` の先頭 7 文字と比べて絞り込む（タイムゾーンで月がずれないようにする）。
- 金額は `1,200円` の形で出す。

## カテゴリ

固定で、利用者は増やせない。色はデザイントークンの名前を持つ。

| type | id | 名前 | 色 |
|---|---|---|---|
| expense | `food` | 食費 | cat-1 |
| expense | `daily` | 日用品 | cat-2 |
| expense | `housing` | 住居 | cat-3 |
| expense | `utilities` | 光熱費 | cat-4 |
| expense | `transport` | 交通 | cat-5 |
| expense | `fun` | 娯楽 | cat-6 |
| expense | `other-expense` | その他 | cat-7 |
| income | `salary` | 給与 | cat-3 |
| income | `other-income` | その他 | cat-7 |

## 保存

- localStorage のキー `kakeibo:v1` に `{ "version": 1, "transactions": Transaction[] }` を 1 つ置く。
- 画面は localStorage を直接触らず、保存の層を通す。
- キーが無いときは空として始め、最初に記録したときに保存する。
- 値が JSON として読めない・`version` が違う・形が合わないときは上書きしない。画面に理由を出し、元の値を残す。
- 保存に失敗したとき（容量超過など）は、画面に理由を出し、変更前の状態のままにする。

## 画面

1 ページ。ヘッダーの下を、広い画面では 2 列（左が広い main、右が side）、狭い画面では 1 列に並べる。
機能はそれぞれ置き場所（`header`・`main`・`side`）と並び順を持つ。

| 置き場所 | 並び順 | 機能 |
|---|---|---|
| header | 10 | 月の切り替え |
| header | 50 | CSV の書き出し |
| header | 100 | 収支の登録 |
| main | 10 | 月の要約 |
| main | 100 | 取引の一覧 |
| side | 10 | カテゴリ別の内訳 |
| side | 20 | 月ごとの推移 |

### 表示中の月

- 表示中の月は URL のクエリ（`?month=2026-09`）に持ち、再読み込みしても保つ。
- クエリが無いか正しくなければ今月とする。
- ヘッダーに `2026年9月` の形で出す。
- 一覧・要約・内訳は表示中の月を、推移は表示中の月までの 6 か月を指す。

## 機能

各節が Issue 1 件の粒度である。

### 収支の登録

- ヘッダーのボタンからダイアログを開き、収支（既定は支出）・日付（既定は今日）・金額・カテゴリ・メモを入力して記録する。
- 収入と支出を切り替えると、カテゴリの選択肢も切り替わる（既定はそれぞれの先頭）。
- 金額は 1 以上の整数だけ受け付ける。カンマ付きの入力（`1,200`）も受け付ける。
- 入力の誤りは、該当する欄の下に理由を出し、記録のボタンを押せないようにする。金額を入れる前は理由を出さない。
- 記録したらダイアログを閉じる。保存に失敗したら、ダイアログに理由を出して開いたままにする。

### 取引の一覧

- 表示中の月の取引を、日付の新しい順（同じ日なら記録の新しい順）に並べる。
- 各行に日付（`9/5`）・カテゴリ（色の点と名前）・メモ・金額を出す。金額は収入なら収入の色、支出なら支出の色にする。
- 取引の無い月は「この月の取引はまだありません。」と出す。

### 月の要約

- 見出しは「今月の収支」とし、表示中の月の収入の合計・支出の合計・差額（収入 − 支出）を横に並べる。
- 収入の合計は収入の色、支出の合計は支出の色にする。
- 差額は、正なら収入の色、負なら支出の色、0 なら色を付けない。負のときは `-1,200円` の形で出す。
- 取引の無い月は、3 つとも `0円` とする。

### カテゴリ別の内訳

- 見出しは「支出の内訳」とし、表示中の月の支出をカテゴリごとに合計して、金額の多い順に並べる。金額が同じなら「カテゴリ」の表の順とする。
- 各行に色の点・カテゴリ名・金額・割合を出し、その下にカテゴリの色の横棒を置く。
- 割合は支出の合計に対する % で、小数点以下を四捨五入する（合計が 100 にならなくてもよい）。
- 横棒の長さは、最も多いカテゴリをいっぱいとした比で決める。
- 支出の無いカテゴリは出さない。支出の無い月は「この月の支出はまだありません」と出す。

### 月ごとの推移

- 見出しは「6 か月の推移」とし、表示中の月までの 6 か月を古い順に縦に並べる。
- 各月に、月（`9月`）・収入の合計と横棒・支出の合計と横棒を出す。
- 横棒の長さは、6 か月の収入と支出のうち最も大きい値をいっぱいとした比で決める。
- 取引の無い月も `0円` として並べる。

### CSV の書き出し

- ヘッダーのボタン（「CSV」）で、表示中の月の取引を CSV のファイルとしてダウンロードする。ファイル名は `kakeibo-2026-09.csv`。
- 行の順は「取引の一覧」と同じ。1 行目は見出しで、列は `日付,収支,カテゴリ,金額,メモ`。
- 日付は `2026-09-05`、収支は `収入` か `支出`、金額はカンマの無い整数とする。
- 文字コードは UTF-8 の BOM 付き（Excel で文字化けしないため）、改行は CRLF とする。
- カンマ・改行・`"` を含む値は、RFC 4180 に従って `"` で囲み、`"` を `""` にする。
- 取引の無い月は、ボタンを押せないようにする。

### 月の切り替え

- ヘッダーに、前の月・次の月へ移るボタンと、今月へ戻るボタンを置く。
- 移ると表示中の月（URL のクエリ）が変わり、ブラウザの戻るで前の月に戻れる。
- 今月を表示しているときは、今月へ戻るボタンを押せないようにする。
