# デザイン

画面の見た目を、誰が作っても同じになるように決める。
値の SSoT は `src/index.css`、部品の SSoT は `src/ui/` で、この文書はその使い方を決める。

## 原則

- 画面は `src/ui/` の部品と、下記のトークンのクラスだけで組む。
- 任意の値（`text-[13px]`）・色の直書き（`#fff`・`rgb(…)`）・`style` 属性は `npm run lint` で落ちる。部品の中（`src/ui/`）だけは使ってよい。
- 欲しい部品やトークンが無いときは、近いものに寄せる。寄せられないときだけ `src/ui/` か `src/index.css` に足し、この文書の表にも書く。足したことは PR の説明に書く。
- ライトとダークは OS の設定で切り替わる。色はトークンで書けば両方に効く。

## 色のトークン

クラスは `bg-<名前>`・`text-<名前>`・`border-<名前>` の形で使う。Tailwind の既定の色（`blue-500` など）は無い。

| 名前 | 用途 |
|---|---|
| `bg` | ページの背景 |
| `surface` | カード・ダイアログ・ヘッダーの背景 |
| `surface-muted` | 横棒の地・選んだ項目の背景・ホバー |
| `border` | 枠線・区切り線 |
| `text` | 本文 |
| `text-muted` | 補足（日付・メモ・空の状態の文） |
| `primary` / `on-primary` | 主なボタンの背景と文字 |
| `income` | 収入の金額・横棒 |
| `expense` | 支出の金額・横棒 |
| `danger` | 入力の誤り・保存の失敗 |
| `cat-1`〜`cat-7` | カテゴリの色（`docs/product/spec.md` の「カテゴリ」） |

色の名前からクラスへの対応は `src/ui/colors.ts` が持つ。`bg-${color}` のように組み立てると Tailwind がクラスを作らないため使わない。

## 部品

| 部品 | 使うところ |
|---|---|
| `Card` | 画面の区画。見出しを持ち、テストでは `getByRole("region", { name: 見出し })` で指せる |
| `Button` | ボタン。`variant` は `primary`（主な操作 1 つ）・`secondary`・`danger`・`ghost` |
| `Dialog` | モーダル。開いている間だけ中身を描く |
| `Field` / `Input` / `Select` | 入力欄。`Field` がラベルと誤りの理由を結び付ける |
| `Amount` | 金額。`tone` で収入・支出・符号の色を選ぶ |
| `CategoryDot` | 色の点 |
| `Bar` | 横棒。グラフはこれを並べて描き、数値は隣に文字で出す |

## 並べ方

- 余白は Tailwind の既定の段階（`gap-2`・`gap-4`・`p-4` など）を使う。区画どうしは `gap-4`、区画の中は `gap-2`〜`gap-3`。
- 金額は右にそろえ、桁をそろえる（`Amount` が `tabular-nums` を付ける）。
- 見出しは `Card` の `title` を使い、区画の中に別の大きな見出しを置かない。
